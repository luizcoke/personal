# Saude

Este espaco e para acompanhamento de saude pessoal, com foco inicial em pressao arterial.

## Arquivos

- `pressao-arterial-registros.md`: log principal de medicoes.
- `pressao-arterial-resumo.md`: consolidado por periodo (media semanal/mensal).
- `_PROTOCOLO_MEDICAO.md`: padrao para medir de forma consistente.

## Rotina sugerida

1. Medir 1 a 2 vezes ao dia, sempre em condicoes parecidas.
2. Registrar imediatamente no arquivo de registros.
3. Revisar o resumo 1 vez por semana.
4. Levar os registros para consulta medica quando necessario.

> Aviso: este material nao substitui orientacao medica.
